## Delusional Obsidian

一种卡片笔记盒的具体实践，旨在提供无感的记录过程，让自动化助你顺畅写作。

![[Source/500_Attachements/501_Images/1_README_20260207.png]]

## 项目理念

摆脱依赖于文件树整理分类的传统笔记组织管理形式，利用元数据+逻辑视图梳理脉络框架。

![[Source/500_Attachements/501_Images/2_README_20260207.png]]

## 具体使用流程说明

初始文件被集中创建在`Toolkit/02_Buffer`中，并利用Templater插件自定义触发路由模板`Toolkit/00_Template/Router`操作，集中选择文件数据和存储位置。进入示例库，按下`cmd+o`或者`ctrl+o`新建文件即可感受遍历。当然此操作也适用于双链语法，当我们写作的时候可以随时\[\[新建一个并未创建的卡片，此卡片创建过程也是走的Router。
