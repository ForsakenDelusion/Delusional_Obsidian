试图这样统计一圈一圈，但实际上这样depth就不是按照深度统计了，而是弹出一个节点就统计一次
```cpp
while(!q.empty()){
    depth++;   // ❌ 每弹出一个点就加1
    auto cur = q.front();
    q.pop();
    ...
}
```
正确的写法是用dist数组,`dist[x][y]` 表示从起点走到这里的最短步数，BFS 第一次到达就是最短
```cpp
dist[cx][cy] = dist[x][y] + 1;
```
(x,y)为现在的位置，走一步到达相邻格子 (cx,cy)，那么到达 (nx,ny) 的步数 = 到 (x,y) 的步数 + 1；递推的感觉
