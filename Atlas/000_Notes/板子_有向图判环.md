# 有向图判环

## 核心方法：DFS 三色标记法

### 状态定义
| 状态 | 含义 | 遇到时的处理 |
|-----|------|-------------|
| `0` (白) | 未访问 | 继续 DFS |
| `1` (灰) | **当前递归栈中** | **回边！有环** |
| `2` (黑) | 已处理完 | 交叉边，无环 |

### 为什么必须用三色？
双色法（visited[]）会误判：
```
    1 → 2
    ↓   ↓
    3 → 4
```
走 `1→2→4` 后，4 标记为已访问。再走 `1→3→4`，双色法会认为遇到已访问节点 = 有环 ❌

三色法区分「当前路径」vs「历史访问」：
- `state[4] == 2`（黑色）→ 只是别的分支访问过，无环 ✅
- `state[x] == 1`（灰色）→ 当前路径上再次遇到，有环 ✅

### 代码模板
```cpp
vector<vector<int>> graph;  // 邻接表
vector<int> state;          // 0=未访问, 1=访问中, 2=已访问完

bool dfs(int u) {
    state[u] = 1;  // 标记为访问中（灰色）
    for (int v : graph[u]) {
        if (state[v] == 1) return true;   // 遇到回边，有环
        if (state[v] == 0 && dfs(v)) return true;  // 子路径有环
    }
    state[u] = 2;  // 标记为已访问完（黑色）
    return false;
}

bool hasCycle(int n) {
    state.assign(n, 0);
    for (int i = 0; i < n; i++) { // 这个的用法是防止图中含有多个连通分量
        if (state[i] == 0 && dfs(i)) 
            return true;
    }
    return false;
}
```

## 方法二：拓扑排序（Kahn算法）

```cpp
bool hasCycle(int n) {
    vector<int> indegree(n, 0);
    for (auto& edges : graph) 
        for (int v : edges) indegree[v]++;
    
    queue<int> q;
    for (int i = 0; i < n; i++) 
        if (indegree[i] == 0) q.push(i);
    
    int cnt = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cnt++;
        for (int v : graph[u]) 
            if (--indegree[v] == 0) q.push(v);
    }
    return cnt != n;  // 未处理完所有节点 = 有环
}
```

## 对比选择

| 方法 | 适用场景 |
|-----|---------|
| **DFS三色** | 需要输出具体环的路径；代码更短 |
| **拓扑排序** | 需要拓扑序；图很大时更稳定 |

## 常见陷阱

1. **只记双色标记** → 误判交叉边为有环
2. **节点编号从0开始** → 注意题目是 `0~n-1` 还是 `1~n`
3. **图不连通** → 要对每个未访问节点都启动 DFS
