cpp中模运算 `a % b` 本质上是计算 `a - (a / b) * b`，需要先执行除法 `a / b`。

>别的语言中是不是呢？

## 避免模0的判断
```cpp
for(auto &it : bit){
if(it == 0 || num % it != 0){ // 添加对0的检查
return false;
}
```
这里利用了 C++ 的**短路求值**：当 [it == 0](vscode-file://vscode-app/Applications/Visual%20Studio%20Code.app/Contents/Resources/app/out/vs/code/electron-browser/workbench/workbench.html) 为 `true` 时，`||` 后面的表达式不会被执行，从而避免了除以零的错误
