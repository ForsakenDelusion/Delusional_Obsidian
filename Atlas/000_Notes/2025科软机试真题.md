# 题目 1：偶数编号单词逆置

## 题目描述

输出一行字符串，表示将所有**偶数编号**单词逆置后的结果字符串。

字符串按单词划分为编号 $0, 1, 2, \dots$。

## 输入描述

输入一行包含若干个单词的字符串，单词之间用空格分隔。

## 输出描述

输出一行字符串，表示处理后的结果。

## 样例 1

**输入**

```
ew love ctsu
```

**输出**

```
we love ustc
```

**解释**

字符串按单词划分为：`ew` (编号 0)、`love` (编号 1)、`ctsu` (编号 2)。

将偶数编号单词逆置：`ew` $\to$ `we`，`ctsu` $\to$ `ustc`；奇数编号单词 `love` 保持不变。因此输出为 `we love ustc`。

**错误原因**：`cin >>` 会自动跳过连续空格，导致无法保留原始空格格式

### 关键修正点

| 问题 | 原代码 | 修正后 |
|------|--------|--------|
| **读取方式** | `cin >> s_tmp` 跳过空格 | `getline(cin, s)` 保留整行 |
| **输出空格** | 无法控制 | 边遍历边输出，空格原样打印 |
| **单词处理** | 存vector再统一处理 | 边遍历边收集，遇空格立即输出 |

### 正确思路

```cpp
string s;

for(遍历每个字符) {
    if(是空格) {
        输出之前收集的单词（偶数编号则逆置）
        输出空格（原样保留）
    } else {
        收集到当前单词
    }
}
// 别忘了处理最后一个单词
```

**核心原则**：不要用 `cin >>` 做需要保留空格的字符串输入，用 `getline` + 手动解析。


# 题目 2：32 进制转 8 进制

## 题目描述

数据保证字符串 $s$ 仅由字符 `0-9`、`A-V` 构成。

输出一个字符串，表示将 $s$ 转换为 8 进制后的结果。

## 输入描述

输入一个字符串 $s$（代表 32 进制数）。

## 输出描述

输出转换后的 8 进制字符串。

## 样例

### 样例 1

**输入**

```
V
```

**输出**

```
37
```

**解释**

`V` 在 32 进制中表示数值 31，而 31 的 8 进制表示为 `37`。

### 样例 2

**输入**

```
0
```

**输出**

```
0
```

**解释**

`0` 在 32 进制中表示数值 0，其 8 进制表示为 `0`。

## 复盘

**错误原因**：`pow(32, i)` 是浮点数运算，精度有限；且 32^20 远超 `long long` 范围

### 关键修正点

| 问题 | 原代码 | 修正后 |
|------|--------|--------|
| **进制转换** | `sum += itmp * pow(32,i)` 精度丢失 | 32进制→2进制→8进制，字符串处理 |
| **数值溢出** | `int sum` 存不下大数 | 不用数值计算，用位运算/字符串 |

### 正确思路：利用 32=2⁵, 8=2³ 的关系

**转换链：32进制 → 二进制 → 8进制**

```cpp
// 1) 32进制转二进制字符串
// 每个32进制字符 → 5位二进制（不足补前导0）
string bin;
for(char c : stmp) {
    int val = mp[c];
    // 转5位二进制，比如 3 → "00011"
    for(int i = 4; i >= 0; i--) {
        bin += ((val >> i) & 1) ? '1' : '0';
    }
}

// 2) 二进制转8进制
// 从右往左每3位一组（不足左边补0）
while(bin.size() % 3 != 0) bin = "0" + bin;

string res;
for(int i = 0; i < bin.size(); i += 3) {
    int val = (bin[i]-'0')*4 + (bin[i+1]-'0')*2 + (bin[i+2]-'0');
    res += '0' + val;
}

// 3) 去掉前导0（但保留至少一个0）
int pos = 0;
while(pos < res.size()-1 && res[pos] == '0') pos++;
cout << res.substr(pos);
```

### 更简洁的写法：直接用位运算

```cpp
string s; cin >> s;
string bits;

// 32进制 → 二进制
for(char c : s) {
    int v = (c <= '9') ? c-'0' : c-'A'+10;
    for(int i = 4; i >= 0; i--) 
        bits += ((v>>i)&1) + '0';
}

// 二进制 → 8进制（从后往前每3位）
string oct;
for(int i = bits.size(); i >= 0; i -= 3) {
    int v = 0;
    for(int j = max(0,i-3); j < i; j++) 
        v = v*2 + (bits[j]-'0');
    oct += '0' + v;
}
reverse(oct.begin(), oct.end());

// 去前导0
int i = 0; 
while(i < oct.size()-1 && oct[i] == '0') i++;
cout << oct.substr(i);
```

**核心原则**：大数进制转换不要用数值计算，用**字符串/位运算**；善用 32=2⁵, 8=2³ 的幂次关系。

# 题目 3：最小删除区间 (区间调度问题)

## 题目描述

给定一堆区间，其中每个区间由四个参数描述：左端点下标 $l$、右端点下标 $r$、左端点是开还是闭、右端点是开还是闭。

你需要删除**尽可能少**的区间，使得剩余区间**两两不重合**，输出最小删除区间数。

**注意**：区间端点的开闭会影响“是否重合”的判定。例如 $(2,3)$ 和 $[3,4]$ 不重合，因为前者不包含端点 3。

## 输入描述

第一行输入一个整数 $n$ ($1 \le n \le 10^5$)，表示区间数量。

接下来 $n$ 行，每行输入四个整数：$l, r, lc, rc$，含义如下：

- $l, r$ 为区间端点 ($1 \le l < r \le 10^9$)；
    
- $lc$ 为左端点类型，只能是 1 或 0，分别表示左端点**闭**、左端点**开**；
    
- $rc$ 为右端点类型，只能是 1 或 0，分别表示右端点**闭**、右端点**开**。
    

## 输出描述

输出一个整数，表示为了使剩余区间两两不重合所需删除的**最小区间数**。

## 样例 1

**输入**

```
4
1 2 1 1
2 3 0 0
3 4 1 1
1 3 1 0
```

**输出**

```
1
```

**解释**

四个区间分别为：

1. $[1, 2]$  
    
2. $(2, 3)$  
    
3. $[3, 4]$  
    
4. $[1, 3)$  
    

可以保留 $[1, 2]$、$(2, 3)$、$[3, 4]$ 这三个区间，它们两两不重合：

- $[1, 2]$ 与 $(2, 3)$ 在端点 2 处相接，但后者左端点为开，不包含 2，因此不重合；
    
- $(2, 3)$ 与 $[3, 4]$ 在端点 3 处相接，但前者右端点为开，不包含 3，因此不重合。
    

此时只需删除区间 $[1, 3)$，最小删除数为 1。

# 题目 4：网格最大路径值

## 题目描述

给定一个 $m$ 行 $n$ 列的网格。

$1 \le m \le 20, 1 \le n \le 20, 1 \le mn \le 20$。

接下来 $m$ 行，每行 $n$ 个整数，用空格隔开，表示矩阵 $a$：

- $a_{i,j} = -1$ 表示该格**不可通过**；
    
- 否则 $1 \le a_{i,j} \le 10^4$，表示该格的**价值**。
    

要求从 $(0, 0)$ 到 $(m-1, n-1)$ 的最大可获得价值；如果不存在合法路径，则输出 $-1$。

**路径中不能重复经过同一单元格。**

## 输入描述

第一行输入 $m, n$。

接下来输入矩阵内容。

## 输出描述

输出一个整数，表示最大可获得价值或 -1。

## 样例 1

**输入**

```
3 3
1 2 3
4 -1 5
6 7 8
```

**输出**

```
26
```

**解释**

一种可行路径为：

$(0,0) \to (1,0) \to (2,0) \to (2,1) \to (2,2)$

获得的价值总和为 $1 + 4 + 6 + 7 + 8 = 26$。

由于中间格 $(1,1)$ 为 $-1$ 无法通过，且路径中不能重复经过同一单元格，因此最大价值为 26。
## 我的解法

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;

const int N = 25;
int g[N][N];
bool vis[N][N];
int n,m;

int dx[] = {1,0,-1,0};
int dy[] = {0,-1,0,1};

int max1 = -1;
int sum = 0;

void dfs(int x,int y){
    if(x == n && y == m){
        // TODO操作
        if(sum > max1){
            max1 = sum;
        }
        return;
    }
    // 更新
    for(int i = 0;i<4;i++){
        int cx,cy;
        
        cx = x+ dx[i];
        cy = y+ dy[i];


        if(cx<1||cy<1||cx>n||cy>m) continue;
        if(vis[cx][cy] == true) continue;
        vis[cx][cy] = true;
        sum+=g[cx][cy]; // 拿上这个地方的钱
        dfs(cx,cy);
        sum-=g[cx][cy];
        vis[cx][cy] = false;
    }


}

signed main(){

    cin >> n>>m;
    memset(vis,false,sizeof(vis));
    // 输入图数据
    for(int i = 1;i<=n;i++){
        for(int j = 1;j<=m;j++){
            int tmp;
            cin >> tmp;
            if(tmp == -1) {
                vis[i][j] = true;
            }
            g[i][j]= tmp;
        }
    }

    // 开始dfs
    g[1][1] = -1;
    dfs(1,1);
    cout << max1;

return 0;
}
```

## 复盘

**错误原因总结**：起点值丢失 + 边界情况遗漏

### 关键修正点对比

| 问题 | 原代码 | 修正后 |
|------|--------|--------|
| **起点不可达判断** | ❌ 无 | ✅ 先判断 `if(g[1][1]==-1) return -1` |
| **起点值累加** | ❌ `sum=0` 开始DFS，起点值被覆盖 | ✅ `sum += g[1][1]` 再DFS |
| **起点访问标记** | ❌ 仅 `vis[1][1]=true`，但把值设为-1 | ✅ 先累加，再标记，最后设-1 |

### 易错点：DFS起点值处理流程

**错误写法（原代码）：**
```cpp
g[1][1] = -1;      // ❌ 直接覆盖，起点值丢失！
dfs(1,1);          // sum从0开始，没加上起点
```

**正确流程：**
```cpp
// 1. 特判起点不可达
if(g[1][1] == -1) return -1;

// 2. 累加起点值到sum
sum += g[1][1];

// 3. 标记起点已访问
vis[1][1] = true;

// 4. (可选) 设为-1防止重复计算
g[1][1] = -1;

// 5. 开始DFS
dfs(1, 1);
```

**核心原则**：DFS的`sum`要从**当前节点值已累加**的状态开始，而不是进去再算。
