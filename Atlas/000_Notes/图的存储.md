## 边集数组

一个Edge结构体包含起点，终点和权重，即可表示一条边；

优点是省空间，缺点是便利开销太大

```cpp
struct edge {
  int u, v, w;
} e[M]; // 1. 结构体定义边

void dfs(int u) {
  vis[u] = true; // vis是已访问过的节点
  // 2. 核心操作：扫描整个边集数组
  for(int i=1; i<=m; i++) {
    if(e[i].u == u) { // 检查第i条边是否以u起点
      int v = e[i].v;
      if(vis[v]) continue; // 如果已经访问过，那就跳过
      dfs(v);
    }
  }
}
```
