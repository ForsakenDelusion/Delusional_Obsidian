```cpp
int fastPow(int a, int b) {
    int res = 1;         // 结果初始化为 1 (乘法的单位元)
    while (b > 0) {      // 只要指数还没处理完
        if (b % 2 == 1) { // 如果当前指数是奇数 (二进制对应位为 1)
            res *= a;    // 把当前的“底数贡献”乘进结果
        }
        a *= a;          // 底数翻倍：a^1 -> a^2 -> a^4 -> a^8...
        b /= 2;          // 指数减半 (相当于二进制右移一位)
    }
    return res;
}
```

上面的还不太好理解，直接模拟位其实更好想

$a^n = a \times a \times \cdots \times a$, 暴力的计算需要 O(n) 的时间。  
快速幂使用二进制拆分和倍增思想, 仅需要 O(logn) 的时间。

对 $n$ 做二进制拆分, 例如, $3^{13} = 3^{(1101)_2} = 3^8 \cdot 3^4 \cdot 3^1$,  
对 $a$ 做平方倍增, 例如, $3^1, 3^2, 3^4, 3^8 \cdots$。

$n$ 有 $\log n + 1$ 个二进制位, 我知道了 $a^1, a^2, a^4, a^8, \ldots, a^{2^{\log n}}$ 后,  
只需要计算 $\log n + 1$ 次乘法就可以了。

```cpp
int quickpow(int a, int n){
    int res = 1;
    while(n){
        if(n & 1) res = res*a; // 如果该位有效，那就乘进结果
        a = a*a; // 进一位，位权就要增长一位
        n >>= 1;
    }
    return res;
}
```
