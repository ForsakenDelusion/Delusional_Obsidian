## 欧几里得算法（辗转相除法）

已知两个数 $a$ 和 $b$，求出二者的最大公约数

证明：$gcd(a,b) = gcd(b, a\%b)$ 

> 注意这一步等式是为了不断的缩小范围

设 $a > b$, $a\%b = a - kb$，其中 $k = \left\lfloor \frac{a}{b} \right\rfloor$。例如，$7\%3 = 7 - 2*3$。

(1) 若 $d$ 是 $(a,b)$ 的公约数，则 $d|a$（代表可以整除的意思） 且 $d|b$，则 $d|(a - kb)$(可以拆开来看，分别用d整除a和kb，发现都是可以被整除的)，则 $d|(a\%b)$ 故 $d$ 也是 $(b, a\%b)$ 的公约数。

(2) 若 $d$ 是 $(b, a\%b)$ 的公约数，则 $d|b$ 且 $d|(a - kb)$，则 $d|(a - kb + kb) = d|a$，故 $d$ 也是 $(a,b)$ 的公约数。

所以 $(a,b)$ 和 $(b, a\%b)$ 的公约数是相同的，故最大公约数也相同。

递归求解，直到 $a\%b == 0$，此时的 $b$ 就是最大公约数

```c
int gcd(int a, int b){
    if(b == 0) return a;
    return gcd(b, a % b);
}
```

```
gcd(28, 16)
gcd(16, 12)
gcd(12, 4)
gcd(4, 0)
return 4
```
