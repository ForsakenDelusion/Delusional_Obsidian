```cpp
for (int i = 0; i < n; i++) {
    cout << res[i] << (i == n - 1 ? "" : " ");
}
cout << endl;
```

但是以上写法依赖于输入序列的索引，但是输出序列可能并不按照这个顺序，比如1 2 3 4 5，可能我们只需要输出2和4，这时候4就不满足上面的要求，会多输出一个空格；

曲线救国法是，在弄一个数组存输出的序列，或者用下面的方法

```cpp
bool first = true; // 标记是否为第一个输出的元素
for(int i = 0; i < m; i++){
    int tmp;
    cin >> tmp;
    if(A[tmp]){
        if(!first) cout << " "; // 如果不是第一个，先补空格
        cout << tmp;
        first = false; // 之后的所有元素都不是第一个了
    }
}
```
