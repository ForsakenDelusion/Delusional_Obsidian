# 兵棋肉鸽I

## 题目描述

给定 $k$ 种士兵兵棋的名字（用一个大写字母表示），及其对应的战斗力值 $a_i$。再给定一个大小为 $n \times m$ 的棋盘，棋盘中每个位置是一个字符，可能是某个兵棋的名字，也可能是 $.$，表示该位置没有兵棋。

请计算棋盘中出现的所有兵棋的战斗力值之和。

## 输入描述

第一行一个整数 $k$（$1 \le k \le 26$），表示兵棋种类的数量。

接下来 $k$ 行，每行包含一个字符 $s_i$ 和一个整数 $a_i$（$s_i$ 为一个大写字母，$1 \le a_i \le 10^5$），表示角色 $s_i$ 的战斗力值为 $a_i$。

接下来一行两个整数 $n$、$m$（$1 \le n \le 100, 1 \le m \le 100$），表示棋盘的行数与列数。

接下来 $n$ 行，每行一个长度为 $m$ 的字符串，仅由大写字母与 $.$ 组成，表示棋盘每一行的内容。

数据保证棋盘中出现的字母一定在给定的 $k$ 种兵棋中，且每种兵棋字母互不相同。

## 输出描述

输出一个整数，表示棋盘中所有兵棋对应权值的总和。

### 样例1

#### 输入

```
2
A 1
B 2
2 2
AA
.B
```

#### 输出

```
4
```

#### 解释

棋盘中 A 出现 2 次，战斗力值总和为 $1 * 2 = 2$；B 出现 1 次，战斗力值总和为 $2 * 1 = 2$。

因此最终输出 $2 + 2 = 4$。

#include<bits/stdc++.h>

    zhonglei.push_back(tmp);

int n,m;

    for(int j = 1;j<=m;j++){
        char c_tmp;

            }
        }

}

# 兵棋肉鸽

## 题目描述

给出 $k$ 种士兵棋子的名字（用一个大写字母表示）及其形状。棋子形状用字符矩阵表示，大小固定且不超过 $2 \times 2$。

- 形状中等于其名字的大写字母表示该位置被该棋子占用。
    
- 形状中用 `.` 表示该位置不被占用（可与其他棋子部分重叠或为空）。
    
    随后给出一个大小为 $n \times m$ 的棋盘。棋盘中每个格子可能是一个棋子的名字，也可能是 `.`（表示空）。
    
    请判断给出的棋盘是否可以由上述若干个棋子组合而成。每种棋子可使用多次（包含 $0$ 次），但在放置时不允许旋转。重叠或一个棋子占据多个不相同名字的格子是不允许的。
    

## 输入格式

第一行：一个整数 $k$ ($1 \le k \le 26$)，表示棋子种类的数量。

接下来对于每种棋子，输入如下内容：

- 第一行：一个字母 $c_i$，表示棋子名字。
    
- 第二行：两个整数 $r_i, c_i$ ($1 \le r_i, c_i \le 2$)，表示形状矩阵的行数和列数。
    
- 接下来 $r_i$ 行：每行一个长度为 $c_i$ 的字符串，由 $c_i$ 或 `.` 组成。
    
    最后输入棋盘：
    
- 第一行两个整数 $n, m$ ($1 \le n, m \le 1000$)，表示棋盘的行数和列数。
    
- 接下来 $n$ 行：每行一个长度为 $m$ 的字符串，由大写字母或 `.` 组成。
    

## 输出格式

若棋盘合法输出 `Yes`，否则输出 `No`。

## 样例

**样例 1 输入：**

```
3
A
1 2
AA
B
2 1
B
B
C
2 1
C
.
3 4
.AAB
CAAB
CC.B
```

**样例 1 输出：**

```
Yes
```

**样例 2 输入：**

```
2
A
1 2
AA
B
2 1
B
B
3 4
.AAB
CAAB
CC.B
```

**样例 2 输出：**

```
No
```

## 提示

1. 棋盘上的每个字母必须属于一个且仅属于一个棋子。
    
2. 棋子占用的位置字符必须与其名字一致。
    
3. 棋盘上的 `.` 不计入任何棋子。
