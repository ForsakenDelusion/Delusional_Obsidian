KEY INSIGHTS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. IMPLICIT vs EXPLICIT
   ✅ Areas are IMPLICITLY defined (in template)
   ❌ Areas are NOT EXPLICITLY instantiated (no 200_Areas/ folder)
   → Projects reference areas as STRING metadata only

2. HIERARCHY
   Area (ongoing responsibility) → Project (time-bound goal) → Cards (knowledge)
   └─ One area can contain MANY projects
   └─ Each project can link to MANY cards
   └─ Cards are reusable across projects

3. TIME-BOUND DISTINCTION
   Area = NO deadline (ongoing forever)
   Project = HAS deadline (due_date field)
   → This is the MAIN distinguishing factor

4. CURRENT STATE
   - Learning: 5 projects clustered (exam prep + knowledge management)
   - Development: 1 project (experimental/tools)
   - Life: 1 project (maintenance)
   - Research: 0 projects (defined but unused)
   - Writing: 0 projects (defined but unused)
